Telecom Customer Churn Analysis

Overview
This project analyzes telecom customer behavior to identify the main factors responsible for customer churn. The analysis focuses on contract type, monthly charges, payment methods, and technical support usage to generate business insights and customer retention strategies.

Dataset Information
- Total Records: 7,043 customers
- Industry: Telecom
- Target Variable: Churn

Objectives
- Identify customer churn patterns
- Analyze customer behavior and service usage
- Find high-risk customer segments
- Suggest strategies to improve customer retention

Key Insights
- Overall churn rate was around 26.5%
- Month-to-month contract customers showed the highest churn
- Customers with higher monthly charges churned more frequently
- Lack of technical support increased churn risk significantly
- Suggested strategies could potentially reduce churn by 15–20%
